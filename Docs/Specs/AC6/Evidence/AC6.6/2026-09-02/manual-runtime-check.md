3. **No target redirect:** stale, allied, inactive, and missing Frontline targets reject; the alternate enemy remains without Advantage.
4. **Atomic durability:** the save coordinator publishes modifiers only after successful replacement. Failure retains Ready/OFFERED/locked state; retry applies once.
5. **Safe/Boss exclusion:** the normalized regular-Combat gate runs before `BattlePreparationRecord.offered()`; both excluded encounter paths leave Cache untouched.
