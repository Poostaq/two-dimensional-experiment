# AC6.5 Brakka Rustbanner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Brakka Rustbanner the first production-selectable commander, start her in the middle frontline slot, and resolve Banner Holder once per round against the deterministic closest active enemy.

**Architecture:** A focused `GoblinCommanderCatalog` composes Brakka from the implemented Scrapshield Bruiser and owns her launcher presentation. Shared formation and reaction APIs select and revalidate action-start targets, while `BattleArena` coordinates resolution without a Brakka skill-ID branch. The existing production launcher carries one pending commander ID into `WorldRunStartService`; the stable Brakka formation ID remains the save/reload authority.

**Tech Stack:** Godot 4, typed GDScript, `.tscn` Control UI, SceneTree test runners, GodotIQ structured inspection/editing/validation/runtime tools, Git.

---
